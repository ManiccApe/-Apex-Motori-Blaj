# A.M.B. 2.6.1 RC5 – Android Widget Stability Patch

- Widget Notizie: layout iniziale leggero, visualizzazione di sicurezza e miniature limitate per evitare problemi di memoria nel launcher.
- Widget Calendario: nuovo layout 6×7 compatibile con RemoteViews, gestione più robusta degli aggiornamenti e fallback sicuro.
- Aggiornamenti GitHub: controllo periodico tramite JobScheduler e notifica delle nuove release per chi ha autorizzato le notifiche.
- Compatibilità prevista Android 10+; correzioni ancora da verificare su dispositivi reali.
- Resta invariata l'esperienza principale di A.M.B. (Video, Brief, Calendario, impostazioni, temi e fonti).

**Versione:** 2.6.1-rc5 · **Version Code:** 265 · **Stato:** pre-release.

**Nota:** nessun invio push immediato alle vecchie installazioni; i controlli automatici vengono introdotti dalla RC5. Per aggiornare un APK già installato occorre una build firmata con la stessa chiave.
