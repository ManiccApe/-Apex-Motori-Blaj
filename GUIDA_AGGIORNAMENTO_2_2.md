# Aggiornare Apex Motori Blaj a 2.2

1. Scarica ed estrai lo ZIP della PATCH.
2. Apri `https://github.com/ManiccApe/-Apex-Motori-Blaj` → Code → Add file → Upload files.
3. Carica **tutti i file e le cartelle estratte** mantenendo i percorsi a partire dalla radice (`app/...` e `README.md`). Sostituisci i file già presenti.
4. Conferma **Commit changes** su `main`.
5. Apri Actions e attendi che `Build Android APK standalone A.M.B.` termini con l'icona verde.
6. Apri la run → Artifacts → scarica `Apex-Motori-Blaj-APK`; estrai `app-debug.apk`.
7. Prima di disinstallare eventuale versione precedente esporta backup delle fonti/preferiti dalle Impostazioni. Con la stessa firma si può aggiornare senza reinstallare; altrimenti potrebbe essere necessaria reinstallazione.
